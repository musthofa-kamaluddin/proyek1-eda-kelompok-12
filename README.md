## Topic
Smart City - Bike Sharing

Analisis ini menggunakan data set Seoul Bike Sharing Demand untuk menganalisis hubungan antara kondis cuaca, waktu, dan jumlah sepeda yang disewa setiap jam di Seoul.

## Dataset

**Nama:** Seoul Bike Sharing Demand

**Sumber:** UCI Machine Learning Repository

**Link:** https://archive.ics.uci.edu/dataset/560/seoul%2Bbike%2Bsharing%2Bdemand

**Lisensi:** Creative Commons Attribution 4.0 International (CC BY 4.0)

Dataset berisi jumlah sepeda publik yang disewa setiap jam pada Seoul
Bike Sharing System, beserta informasi cuaca dan hari libur. Variabel
yang tersedia antara lain jumlah sepeda yang disewa, jam, temperatur,
kelembapan, kecepatan angin, jarak pandang, temperatur titik embun,
radiasi matahari, curah hujan, salju, musim, hari libur, dan functional day.
